# Visual Defect Detector

Image-classification pipeline that flags **defective vs non-defective** manufactured-part images. Built with OpenCV preprocessing, HOG + texture features, and a random forest classifier selected by cross-validation. Achieves **93.8% accuracy (F1 0.94, ROC-AUC 0.93)** on a held-out test set, with zero missed defects. Ships with a clean train/evaluate/inference API and a passing pytest suite.

## How it works

```
synthetic plate image (128x128 grayscale)
        |
  preprocess: resize -> Gaussian blur -> histogram equalization
        |
  features: HOG descriptor (1,764 dims, NumPy implementation)
            + global texture stats: intensity std, dark-pixel fraction,
              Laplacian variance, mean intensity  -> 1,768 dims total
        |
  classifier: RandomForest (200 trees, class-balanced)
        |
  output: "defective" / "non-defective" + confidence
```

## Results (measured, not estimated)

Dataset: 1,200 images (600 per class), stratified 80/20 split, seed 42.
Model selected by 3-fold cross-validated F1 on the training split:

| model | CV F1 |
|---|---|
| RBF-SVM | 0.8625 |
| Logistic regression | 0.8777 |
| **Random forest (chosen)** | **0.9629** |

Held-out test set (240 images):

| metric | value |
|---|---|
| Accuracy | 0.9375 |
| Precision | 0.8889 |
| Recall | 1.0000 |
| F1 | 0.9412 |
| ROC-AUC | 0.9283 |

Confusion matrix `[[TN, FP], [FN, TP]]`: `[[105, 15], [0, 120]]` — no defective part was missed; 15 false alarms out of 120 good parts.

> Honest note: the training images are **synthetic by design** — clean vs. scratched/cracked/dented metal plates rendered procedurally with a fixed seed, so the pipeline trains and evaluates fully offline and reproducibly. All metrics above are real outputs of `scripts/train.py` on synthetic held-out data. The pipeline itself is dataset-agnostic: point the data loader at any labeled image folder to retrain on real images.

## Run it

```bash
pip install -r requirements.txt

# full pipeline: generate data -> train -> evaluate (saves models/model.joblib, metrics.json)
python scripts/train.py

# re-print the metrics
python scripts/evaluate.py

# compare candidate models with 3-fold CV
python scripts/compare_models.py

# classify one image (after training)
python -c "
from src.inference import load_model, predict_image
print(predict_image(load_model('models/model.joblib'), 'data/defective/defective_0001.png'))
"

# tests
pytest tests/ -q   # 11 passed
```

## Layout

```
src/
  data_gen.py    synthetic defect-image generator (deterministic)
  features.py    OpenCV preprocessing + NumPy HOG + texture features
  model.py       random forest training / evaluation metrics
  inference.py   single-image predict -> label + confidence
scripts/
  train.py           end-to-end pipeline
  evaluate.py        pretty-print saved metrics
  compare_models.py  CV comparison behind the model choice
tests/             pytest suite (data, features, model, inference)
```

`data/`, `models/`, and `metrics.json` are generated by `scripts/train.py`
(~30 seconds) and are not committed.
